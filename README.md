# ada-imgui

Ada bindings to [Dear ImGui](https://github.com/ocornut/imgui),
the immediate-mode GUI library, via [cimgui](https://github.com/cimgui/cimgui).

Aimed at the gap on the Ada community's
[Projects to Work on](https://ada-lang.io/docs/projects-to-work-on/)
list: an up-to-date, Alire-installable, well-documented set of
Ada bindings for ImGui, with worked examples.

## Status

Scaffold. Not yet usable. See `CHARTER.md` for the plan and
where the work stands.
